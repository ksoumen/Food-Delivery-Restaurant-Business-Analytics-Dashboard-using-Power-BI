# 🍽️ Food Delivery & Restaurant Business Analytics Dashboard using Power BI

An end-to-end **Power BI Business Intelligence** project that transforms restaurant and food delivery data into actionable business insights. The dashboard provides interactive visualizations for executive reporting, customer analytics, restaurant performance, delivery operations, and advanced business insights using **DAX, Data Modeling, and Time Intelligence**.

---

# 📌 Project Overview

This project demonstrates how Power BI can be used to analyze restaurant business performance by integrating multiple datasets and creating interactive dashboards for business decision-making.

### Business Objectives

- Monitor overall business performance
- Analyze customer behavior
- Evaluate restaurant performance
- Track delivery operations
- Measure operational KPIs
- Enable interactive drill-through analysis

---

# 🛠 Tech Stack

- Microsoft Power BI
- DAX (Data Analysis Expressions)
- Power Query
- Data Modeling (Star Schema)
- Time Intelligence
- Interactive Visualizations
